# Trabajo de Arquitectura de Software

## Backend

Para empezar a usar el backend en este proyecto, se necesita clonar el repositorio usando 

```bash
git clone https://github.com/tonx117/ArquitecturaGrupal
```

Luego, hacer una instalacion de las dependencias usando 

```bash
npm i
```

Y luego inicializar el proyecto usando

```bash
npm run dev
```

### endpoints


get all users, Y post:

```bash
http://localhost:3000/user/
```


get by id, put, delete:

```bash
http://localhost:3000/user/id
```

los datos que se solicitan del usuario para el post y el put son 

name,
email,  
password
